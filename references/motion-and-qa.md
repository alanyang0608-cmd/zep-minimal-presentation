# 动效与画面验收

## 用动作解释阅读顺序

| motion | 表现 | 常用内容 |
| --- | --- | --- |
| static | 直接完整出现 | 作品、截图、结束展示 |
| words | 语义行横向约38px淡入 | 封面、观点、提问 |
| list | 条目纵向约18px错峰 | 目录、章节导航、条目与并列方法 |
| metrics | 轻起伏后停稳 | 指标、比例 |
| timeline | 阶段横向进入，次序不变 | 时间、流程 |
| draw | 按路径实际长度绘制一次 | 趋势图 |

主动作约650ms，曲线约1000ms。错峰总时间受控；不随机跳数、不持续晃动背景、不按汉字逐个飞入。基础CSS是完整终态，动画只描述入场。`data-motion-state`在活动页标记running/idle，便于不同工具观察。

翻回上一页可以改变文字进入方向，但不能颠倒事件顺序。快速翻页立即取消旧动画；取消后恢复基础画面。重播不改变数据、点数和结构。静态页和减少动态效果模式下重播按钮禁用。

## 验收顺序

先用同一版本、同一JSON及相同`--theme`参数执行`build.py deck.json --verify talk.html`。它只读检查成稿是否与生成器完全一致，能发现改色、添加覆盖样式或手改内容；不能替代下面的画面检查。失败时先核对版本和输入，再从JSON重新生成，不修改校验规则掩盖差异。

1. **内容**：页数、顺序、结论、单位、数据定义、来源和必要限定条件。示例不是事实库。
2. **桌面**：在实际演示尺寸或1280×720逐页检查idle终态。标题不压图，图片不失真，图例/单位可读，正文和页脚不碰撞。
3. **手机**：以390×844等窄屏检查；长页可滚动，整页不横向溢出，图表横向滚动只发生在图表容器内。
4. **交互**：前后翻页、首尾边界、目录目标、总览、讲者提示、弹窗关闭、键盘与焦点。
5. **动态**：每类至少观察一次过程和终态，检查重播与快速多次切换，没有旧页回调闪回。比例点数与长度始终真实。
6. **环境**：在可用条件下验证减少动态效果、实际全屏和打印。全屏应隐藏工具栏/导航/进度线，F可切回；讲者提示仍在当前投屏页显示，私下备注请另开手卡。未操作的环境项写明未测，不能把“有代码”当“已验证”。

## 任意浏览器工具可用的只读检查

`scripts/inspect-layout.js`是一段只读函数，返回当前活动页与画布/页脚边界、溢出文本、图片状态及动画终态。使用所在agent的合法浏览器求值工具运行；它不会翻页或写文件。无法执行时用截图和人工检查代替。

自动边界检查只能发现一部分问题。留白不等于空洞，文字没有出界也可能太小；截图检查不可省略。图表容器允许内部横向滚动，其SVG不应被误报为整页溢出。

## 修复顺序

- 内容过密：拆页或移动补充信息到提示；保留必要限定。
- 标题难读：语义断行、减少同页次要信息或拆页。标准模板保留字号；用户要求的排版定制在任务副本实现并说明。
- 数字错误：回到输入数据修复，不只改SVG或样式。
- 点/装饰挡字：让装饰让位，不移动关键文字到不自然的位置。
- 动效残留：取消动画并回到完整基础CSS，修复生命周期，不加长等待掩盖。

报告已做的检查与真实限制，不给没有证据的“全平台完美”“零侵权”“任何模型同效果”保证。
