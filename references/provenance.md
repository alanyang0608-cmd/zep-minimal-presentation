# 素材来源与再使用

## 公共包的来源边界

早期设计探索参考过第三方幻灯片的视觉特征。公共版重新编写了内容契约、生成器、通用布局、样例文字和几何示意；只保留留白、层级、对比、对齐、阅读顺序等一般设计原则。它不将网络模板重新署名后出售或分发。

| 公共资源 | 来源 / 使用范围 |
| --- | --- |
| 说明文档与JSON示例 | 为公共包新写的通用内容；演示数据有明确标签 |
| Python生成器、播放器、CSS | 为公共包新实现的代码；系统字体回退，无第三方运行库 |
| layers / route / window示意 | 代码绘制的基本矩形、路径与圆点；不是产品截图或商标 |
| 预览图、示例HTML | 从本包中性JSON与运行器实际生成；不含私有稿件 |
| 网络参考截图、真实人物、客户案例、商业字体 | 不包含在本包及发布压缩包中 |

源代码、文档和包内新写的示例按[MIT许可证](../LICENSE)提供。MIT要求保留相应版权与许可声明；选择依据可见[MIT说明](https://choosealicense.com/licenses/mit/)。后续导入的素材不会因为被放进本工具而自动取得MIT授权。

## 从参考到自己的表达

先依据实际内容确定叙事，再决定页型和视觉重心。避免同时沿用参考的完整页序、字句、专属图形、装饰布局和品牌气质组合。不能通过去水印、删署名、换色或替换少量词来解决来源问题，也不以“相似度低于某个百分比”作为判断依据。

以美国版权局说明为例，一般思想、方法与其具体文字/图像表达需要区分；具有创造性的具体内容选择与编排也可能得到保护。这只是理解设计复用的一个参考，不是对具体作品或所有司法辖区的权利判断。[Circular 33](https://www.copyright.gov/circs/circ33.pdf)

## 贡献素材时

- 优先使用自己有权分享的内容、可验证的开放许可素材或本包基础几何示意。
- 保留作者、来源、许可与必要修改记录；有署名义务的素材不能删去署名。
- 真实截图检查姓名、头像、账号、联系方式、客户名称、内网地址、文档标题与隐藏提示。去掉可见名字不能保证去标识化完成。
- 不把未经允许的私有稿件、网络模板原图、商业字体或来源不明的媒体打包到仓库。
- 程序扫描只能发现部分文本问题；图片需要看图，来源权利需要核实。公开前检查最终压缩包，而不只检查当前可见页面。

本包未宣称对全球所有既有设计完成相似性检索，也未给出法律上的绝对原创或不侵权保证。设计原则、素材出处和可分发文件应分别核对。
